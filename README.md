# In Loving Memory of Haj Ramezanali Izadi 🤍

A minimalist, digital memorial webpage hosted on GitHub Pages and accessible via a QR code. This project serves as a lasting tribute, preserving cherished memories, photographs, a memorial video, and background music in honor of our beloved grandfather.
